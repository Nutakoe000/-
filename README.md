Интерактивный WEB-сайт "7 Чудес Казахстана" or "7 Wonders of Kazakhstan".


! Цель сайта: информационное просвещение о 7-ми достопримечательностях страны Казахстан. 

! Использованные технологии: JavaScript, CSS, HTML. Без фреймворков.

! Полученный опыт как разработчика: понимание и практика в веб языках и языке разметки, тренировка в fullstack создании "продукта", демонстрация полученных знаний
из документаций, понимание основ web разработки, работа со шрифтами, применение разных способов стилизовки на CSS. Разработка проходила без использования ИИ.

! Содержание: 3 страницы, sidebar, навигация по шапке или же по объектам на Главной странице aka index.html, музыка на сайте, переключение темы, анимации на css,
всплывающие окна, гугл карты (как отдельный переход на саму страницу с точкой объекта, так и карта на самом сайте на странице "Подробности", aka "Чудо-информация" 
aka detals.html)
